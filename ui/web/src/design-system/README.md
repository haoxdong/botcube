# Design-system registry

The one source of the web UI's tokens and parts ([ADR 0094](../../../../../docs/adr/0094-web-ui-is-built-from-one-design-system-registry.md)); the maintainer owns this folder.

- `tokens.css`: every token, the safe-area insets and the layers included. Nothing else reads the raw `env(safe-area-inset-*)` or sets a z-index by number: the layers sit under the stock parts' own z-50, so a menu opens over any sheet.
- `components.ts`: the components list, a typed TypeScript array, one row per part: `name`, `kind` (`stock` from shadcn or AI Elements, unedited, or `ours`), its one `file`, and for ours the names of its whole-app `stories`, which each bot's Storybook runs at 390 with iPhone 15 insets and at 1440, and the DESIGN.md Intended lines it owns. A row's `marks` say what a copy of it looks like, in every source or those its `within` names; its `exceptions` name today's copies, by file, with the ticket that removes each. `LIBRARIES` names stock libraries beyond shadcn and AI Elements, each imported only in its folder: Fluent UI in the agent computer, `src/computer` ([ADR 0093](../../../../../docs/adr/0093-agent-computer-is-shown-as-windows-11.md)). `UNLISTED` names today's UI files outside any row.
- `one-source.ts`: the check, run by `one-source.test.ts`. It fails a listed part's mark outside its file (a stylesheet and component of one name are one part), its exceptions, the stock parts' own files (shadcn's and AI Elements', unedited) and a stock library's folder, naming the part; UI (a stylesheet or a `src/components` component) outside a listed part and `UNLISTED`; a stock library imported outside its folder; and an exception whose copy is gone.
- `viewport.ts`: the one phone breakpoint, 640px, as `PHONE_MAX_WIDTH`, its `PHONE_QUERY`, `DESKTOP_QUERY` (641px up) and `TABLET_QUERY` (641px up, touched), and `useViewport()`, `'phone' | 'tablet' | 'desktop'` (`viewport()` outside React). A stylesheet writes `(max-width: 640px)` or `(min-width: 641px)` out; the check fails any other three-digit width query and any width asked of `matchMedia` outside this file.
- `screens.ts`: the iPhone 15 and 1440 screens the whole-app stories run at (`.storybook/screen.ts`).
